## Goal

Let a PlayStation Plus Premium subscriber stream cloud catalog games (PS5
"pscloud" and PS Now-style "psnow" titles) on Android TV, next to the existing
console Remote Play. No console is needed for cloud sessions.

## Upstream basis

FACT: Pylux (`ForWard-Technologies-LLC/Pylux`, AGPL-3.0 with the OpenSSL
exception, built on chiaki-ng) implements cloud streaming in its shared C
library:

- `lib/src/cloudcatalog_*.c`: unified catalog fetch, merge and cache;
- `lib/src/cloudsession*.c`: Kamaji entitlement resolve, Gaikai server
  allocation, datacenter ping and selection;
- `lib/src/pscloud_audio_reassembler.c` and the extended `session.c`: the cloud
  variant of the stream session.

Its Android JNI exposes `cloudCatalogFetchUnified`, `cloudProvisionSession`
and a `ConnectInfo` extended with cloud fields (launch spec, handshake key,
session ID, port, PSN wrapper type, MTU, RTT). Pinned revision:
`ca87a49a12bab071948f565ca53ffdad790775d3`.

DECISION: the GPSx native engine moves from chiaki-ng `c8bea264` to Pylux
`ca87a49`. Pylux is a superset of chiaki-ng with the same
`com.metallic.chiaki.lib` JNI package, so console Remote Play keeps working.
`ChiakiCompat.kt` must be updated to Pylux's `ConnectInfo` layout in the same
change as the native libraries, because the native code looks up those fields
by name.

## What GPSx does differently

- **PSN login stays between the device and Sony.** On TV, Pylux sends the user
  to `xbgamestream.com`, which returns the NPSSO token, and it logs the response
  body. GPSx does not use that relay. It signs in through an in-app WebView on
  Sony's own login page and reads the `npsso` cookie for
  `ca.account.sony.com`. Manual NPSSO entry is the fallback.
- The NPSSO token is encrypted with an Android Keystore key, never logged,
  never exported in diagnostics, and can be wiped from Settings.
- No QR codes generated by third-party services.
- The UI is the existing Compose TV shell: a new **Cloud** destination with
  sign-in, catalog grid, a game detail view and a "Play" action.

  public distribution.
- NOT_TESTED: everything above until the native build exists.
